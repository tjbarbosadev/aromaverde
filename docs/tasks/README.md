# Tasks

Um arquivo por tarefa da [DECOMPOSICAO.md](../DECOMPOSICAO.md).  
Cada **GitHub Issue** aponta para o arquivo correspondente neste diretório.

| Prefixo | Trilha | Label |
|---------|--------|-------|
| `A*` | App / design system | `track:app` |
| `I*` | Infra homelab | `track:infra` |
| `F*` | Fora da v1 | `track:backlog` |

Começar implementação apenas com liberação explícita da task (normalmente **A0** e/ou **I1**).

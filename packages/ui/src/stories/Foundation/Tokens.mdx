# Design tokens

Fonte canônica: `@aromaverde/ui/styles/tokens.css`.  
Átomos usam classes Tailwind (`bg-sage`, `text-ink`, `font-display`) ou `var(--color-*)` — nunca hex solto no JSX.

Paleta alinhada ao **Earthware** (olive / blush / ink) com empurrão de marca verde.
